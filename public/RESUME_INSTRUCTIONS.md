# Resume Placeholder

To add your resume to this portfolio:

1. Create or export your resume as a PDF file
2. Name it `resume.pdf`
3. Place it in the `/public` directory
4. The "Download Resume" button on the homepage will automatically work

## Alternative Options

If you don't have a PDF resume yet, you can:
- Use online tools like Canva, Resume.io, or Overleaf to create one
- Export from Microsoft Word or Google Docs as PDF
- Generate one programmatically using libraries like react-pdf

The resume download button is located in the Hero section of the homepage.
